# Pulumi

## What is Pulumi?

Pulumi is an Infastructure as Code and secrets management platform that allows you to use familiar programming languages and tools to automate, secure, and manage everything you run in the cloud.  
You can use it with AWS, Azure, Google Cloud and Kubernetes.  

Here, we will use Kubernetes.  

## Differences between Terraform and Pulumi?

Pulumi allows you to use familiar programming languages and tools to build, deploy, and manage your cloud infrastructure.  
However, Terraform use a human-readable language called HCL (HashiCorp Configuration Language)

## How to Install Pulumi?

On Linux:

```sh
curl -fsSL https://get.pulumi.com | sh
```

On MacOS:

```sh
brew install pulumi/tap/pulumi
```
